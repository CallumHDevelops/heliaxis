A template is a copy of a page’s sections, words, pictures and light or dark theme that you can start new pages from. The page’s SEO settings aren’t copied. Handy when you build several similar pages, such as one per town.

## Save a template

1. Open the page in the editor.
2. Click **⋯** in the toolbar, then **Save as template**.
3. Type a **Template name** (it suggests the page name plus "template"). Names must be unique.
4. Click **Save template**. You’ll see **Template saved**.

## Start a page from a template

1. Go back to the CMS dashboard (click **Heliaxis** at the top left of the editor).
2. Under **Create**, click **+ From template**.
3. Scroll the previews and click **Use this →** on the one you want. (The gallery is headed **Choose a case-study template**, but it lists your saved templates.)

The new page is a draft with the template’s name. Rename it and set its web address on the **SEO** tab (see [Page settings and SEO](/admin/help/website/page-settings-and-seo)), then change the words.

> **Good to know:** Templates are shared: everyone who uses the CMS sees the same list. If there are none yet, **+ From template** says **No saved templates yet**.

> **Good to know:** Changing a template’s original page later doesn’t change the template, and pages made from a template don’t change when you save a new template.

> **Watch out:** Saved templates can’t be renamed or deleted in the CMS, so give each one a clear name.

Open the page in the editor and click the **SEO** tab on the left. It’s headed **Page settings** and the page’s name.

## The settings

| Setting | What it does |
| --- | --- |
| **Page title** | The page’s name in the CMS. Must be unique. Changing it also changes the **URL slug** to match (except on the homepage). |
| **Page type** | **Page**, **Landing** or **Case study**. Only used for the badges and filter on the CMS dashboard. The homepage and blog articles are set for you. |
| **Theme** | **Light** or **Dark**. |
| **Page title (SEO)** | The title shown in Google results, for example `Solar Panels Cardiff \| Heliaxis`. |
| **Meta description** | The short description under the title in Google results. Aim for 150–160 characters. |
| **URL slug** | The page’s web address after heliaxis.co.uk, for example `/solar-panels-cardiff`. Must be unique. |
| **Social share image URL** | The picture to show when the page is shared on social media. See the note below. |
| **Canonical URL** | Only needed if the same content lives at another address. See the note below. |
| **Hide from search engines (noindex)** | Tick to ask Google not to list the page. |

Changes save automatically, and go live the next time the website is published.

> **Good to know:** Of the search and sharing settings, the live website uses **Page title (SEO)**, **Meta description** and **Hide from search engines (noindex)**. **Social share image URL** and **Canonical URL** are saved, and go into the file from **⋯ › Export HTML**, but heliaxis.co.uk doesn’t use them yet.

> **Watch out:** Renaming a live page, or changing its **URL slug**, changes its web address once published. Links to the old address (in emails, adverts or the menu) will stop working, so update them too.

## Addresses you can’t use

- `/` belongs to the homepage. Only one page can use it.
- `/blog` is the blog’s front page, and addresses under `/blog/` are for blog articles. Create those from the [Blog page](/admin/help/website/write-a-blog-article).

> **Good to know:** The **AI page builder** fills in the SEO title and description for you. Check them before publishing.

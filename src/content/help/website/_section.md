Everything about heliaxis.co.uk lives under **CMS** in the menu: **Manage CMS** (the page editor), **Blog**, **Website analytics** and **Heatmap**. Changes you make in the editor are saved straight away but only reach the public website when someone presses **Publish**. The page editor needs a bigger screen, so use a tablet or computer for it.

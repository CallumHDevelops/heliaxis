The social media studio is Heliaxis’s tool for creating and scheduling social posts and reels. It’s a separate app at social.heliaxis.co.uk, with its own screens; this help covers getting into it from here.

## Open it

Click **Apps › Social media studio** (on a phone: **More**, then **Social media**). It’s also on the main dashboard under **Apps**.

It opens in the same tab, already signed in, so you don’t need a separate password.

## The first time: confirm your email

Before the app signs you in to the studio for the first time, it checks that the email address on your Heliaxis account really is yours. You only do this once (and it also covers RAMS).

1. You’ll see **Open the social studio without signing in**. Click **Email me a code**.
2. Check your email for a 6-digit code. Type it in and click **Confirm**. The code works for 15 minutes.
3. The studio opens. If you didn’t have a studio account yet, one is set up for you.

If the code doesn’t arrive or has run out, click **Send a new code**. Codes can only be sent every two minutes.

You can always skip this with **open the social studio and sign in as usual**.

> **Once switched on:** One-tap sign-in needs sso.sql run on Setup. Until then, **Email me a code** shows a note that it isn’t switched on yet: use **open the social studio and sign in as usual** instead. Admins: see [Set up one-tap sign-in](/admin/help/admin/one-tap-sign-in).

## If it asks you to sign in anyway

The studio’s own sign-in page appears if:

- one-tap sign-in to the studio hasn’t been set up yet (ask an admin), or
- you don’t have **Social media studio** access here (ask an admin to tick it on the **Users** page), or
- the studio already has an account under your email that it can’t use (for example, not yet confirmed there). Sign in there as usual, or ask an admin.

**RAMS**, **Our team** and **Social media studio** are separate apps. You open them from Heliaxis and they open already signed in as you, so there’s no second password to remember.

## Where to find them

- **RAMS**: **Operations › RAMS** in the top menu, or **RAMS** on a phone’s bottom bar.
- **Our team**: **Team › Our team** (it opens RAMS on our own operatives).
- **Social media studio**: **Apps › Social media studio**, or **More › Social media** on a phone.
- On the dashboard, under **Apps**, each has a card with **Open app ↗**.

You only see the ones your account has access to.

## The first time: confirm your email

The first time you open one, Heliaxis checks the email address on your account is really yours. You only do this once, and it covers both RAMS and the social studio.

1. The page says **Open RAMS without signing in** (or **Open the social studio without signing in**). Press **Email me a code**.
2. Find the email with the 6-digit code. It works for 15 minutes.
3. Type the code and press **Confirm**.

The app then opens, signed in. For the social studio, if you don’t have an account there yet, one is set up for you.

Didn’t get it? Press **Send a new code** (codes can only be sent every two minutes). You can always use the link at the bottom of the page to open the app and sign in as usual instead.

| Message | What to do |
| --- | --- |
| "That code isn’t right. Check the email and try again." | Check the code and type it again. |
| "That code has expired. Send a new one." | Press **Send a new code**. |
| "Too many wrong tries…" | Send a new code, or try again tomorrow. |
| "Codes can only be sent every two minutes…" | Use the code you already have, or ask again shortly. |
| "This isn’t switched on yet: sso.sql needs running in Supabase…" | Ask an admin. Meanwhile, use the link at the bottom of the page to sign in as usual. |

> **Once switched on:** This needs sso.sql (it’s a **From Claude** to-do on the dashboard). If the one-tap sign-in hasn’t been set up at all, these links open the app’s own sign-in page. For admins, see [Set up one-tap sign-in to RAMS and the social studio](/admin/help/admin/one-tap-sign-in).

For what you do inside RAMS on a job, see [RAMS](/admin/help/projects/rams).

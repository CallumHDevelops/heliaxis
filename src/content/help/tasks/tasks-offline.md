The Tasks page works with no connection, on the Android app or in a browser, as long as you’ve opened it on that device before.

## What you can do offline

Everything: add a task, edit it, tick it off, change its status or delete it. Each change shows straight away and is kept on the device until it can be sent.

## How to tell

The line under the **Tasks** heading says where you are:

| It says | Means |
| --- | --- |
| **All changes saved** | Everything’s on the server. |
| **Syncing…** | Sending your changes now. |
| "2 changes waiting to sync" | Online, but some changes haven’t gone yet. |
| "Offline — 2 changes will sync when you’re back online" | No connection; your changes are kept on the device. |
| "Offline — showing your saved copy" | No connection, and nothing waiting. You’re seeing the list as it was last time. |

Changes are sent in the order you made them as soon as the connection is back, and again whenever you come back to the app.

If one can’t be saved (for example, someone else deleted that task meanwhile), a red message says why, with **Dismiss**.

> **Watch out:** Don’t sign out while changes are waiting to sync. Signing out clears Tasks from the device, including anything not yet sent.

> **Good to know:** With no signal you won’t see the **Job:** links on tasks, other people’s latest changes, or anything that arrived since you were last online.

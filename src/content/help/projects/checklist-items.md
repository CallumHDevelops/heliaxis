★ is a key item. ✓ means it ticks itself when the app can see it’s done. Items only show on jobs they apply to. For how the checklist works, see [The Overview tab and its checklist](/admin/help/projects/overview).

## Won

| Item | Key | Ticks itself |
|---|---|---|
| Contract or quote signed | ★ | ✓ |
| Deposit paid (if there’s a deposit) | ★ | ✓ |
| Deposit insurance cover issued | | |
| Survey complete and linked | | ✓ |
